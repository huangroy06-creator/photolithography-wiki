WHY / 為什麼要學微影

微影，就像在晶圓上
精準印出設計圖

想把數十億個電晶體及其連接線放進晶片，得先決定哪些區域要加工，哪些區域要保護。

①

設計圖

晶片有特定形狀的線路與元件，需要圖案化。

②

感光塗層

先在晶圓上塗感光性光阻，建立可控制的材料差異。

③

後續加工

顯影後留下保護圖案，交給蝕刻等製程處理材料。

先記住： 曝光不是用光「直接刻掉矽」，而是先決定光阻圖案。
THE BIG PICTURE / 多層製造

晶片不是只印一次：需要層層對準

KEY IDEA 01

不同層，負責不同功能

晶片由一層層圖案與材料組成，不會只靠一次微影完成。

KEY IDEA 02

Overlay = 對準前一層

即使每一層印得很清楚，位置錯了也可能無法正確連接。

圖為概念示意，不代表特定晶片的真實截面結構。

THE PROCESS / 教學流程

一輪微影的六個關鍵步驟

真實工廠可能增加前後烘烤、量測與清洗等站點；下列先用「正光阻＋蝕刻」理解基本邏輯。

01 / PREP

清潔、表面處理

讓晶圓乾淨，改善光阻附著。

02 / COAT

旋塗與軟烤

鋪上均勻的光阻薄膜。

03 / EXPOSE

對準與曝光

光透過光罩形成反應差異。

04 / DEVELOP

顯影（必要時 PEB）

洗掉特定區域的光阻。

05 / ETCH

蝕刻轉移圖案

加工失去光阻保護的材料。

06 / STRIP

去光阻

移走剩餘暫時性保護層。

重點：PEB 是否需要、站點先後及次數取決於光阻材料與製程，本頁是適合初學者的簡化教學順序。
RESIST CHEMISTRY / 感光材料

正光阻 vs. 負光阻：到底哪裡會留下？

兩者的差異，是曝光後在顯影液中的溶解行為。點選類型看結果。

DEVELOPED PATTERN / 顯影後留下的光阻
保留下來的光阻下方材料
POSITIVE TONE

被曝光的地方 → 較容易被洗掉

顯影後，未曝光區保留光阻；曝光區成為空缺。這是正光阻的概念示意。

兩種光阻都能製作圖案，選用取決於材料、解析度及後續製程需求。
EXPOSURE / 曝光原理

光罩如何把「圖案」傳到光阻上？

01 — MASK

光罩（Reticle）

像一張帶有明暗圖案的精密底片。

02 — OPTICS

投影光學系統

把圖案經光學成像縮小、聚焦到晶圓。

03 — PHOTORESIST

光阻產生反應

光線使不同區域產生化學差異，顯影後可形成圖案。

示意圖未按實際設備光路比例繪製；不同曝光機系統結構並不完全相同。

DEVELOP → ETCH / 圖案轉移

顯影洗掉的是光阻；蝕刻移除的是材料

同樣是「某些地方消失了」，但處理對象不同。這是最容易混淆的基本概念。

STEP A — DEVELOP / 顯影

溶去選定的光阻，露出原本被光阻蓋住的底層材料。

STEP B — ETCH / 蝕刻

被保護的材料保留，沒有光阻保護的目標薄膜可被移除。

再經去光阻（strip），即可留下目標材料圖案；此處以「蝕刻薄膜」為教學例子。

METRICS / 三個不同問題

解析度好，不代表整個曝光就好

01 / CRITICAL DIMENSION
CD

「線寬對不對？」

圖案尺寸是否符合目標。

02 / ALIGNMENT
Overlay

「疊的位置對不對？」

新圖層是否與舊圖層對齊。

03 / PRODUCTIVITY
WPH

「每小時幾片？」

Throughput（產能）常用 wafers per hour 表達。

關聯： 多層晶片不只要印得細（CD），還得疊得準（Overlay），同時維持合理產能（Throughput）。
MYTHS / 常見誤解

四個要避免的直覺陷阱

MISCONCEPTION 01

✗ 曝光 = 蝕刻矽

✓ 曝光先讓光阻產生反應差異；蝕刻通常是後續加工。

MISCONCEPTION 02

✗ 正光阻照到光就留下

✓ 正光阻的曝光區在顯影時較容易被移除。

MISCONCEPTION 03

✗ 只看波長就能預測 CD

✓ 還要看 NA、k₁，甚至更多製程條件。

MISCONCEPTION 04

✗ CD 很小就不必管 Overlay

✓ 圖案尺寸與層對層位置都是重要指標。

如果要用一句話帶走今天的重點：「先在光阻做圖案，再把圖案轉到材料上；每層要印得細，也要疊得準。」
